# خطة تنفيذ مشروع Beacon Hub

## 1. التقنيات المتفق عليها

- **الواجهة الأمامية:** HTML5 + CSS العادي + JavaScript عادي (Vanilla JS)
- **الواجهة الخلفية:** Node.js + Fastify
- **قالب العرض:** EJS
- **قاعدة البيانات:** SQLite مع مكتبة `better-sqlite3`
- **ORM (لاحقًا):** Drizzle ORM في حال تطلب الأمر تنظيم أكثر

## 2. المبادئ الأساسية

- **إمكانية الوصول أولاً:** ستكون أولوية أساسية وليس ميزة إضافية.
- **HTML دلالي:** استخدام عناصر HTML الصحيحة مثل `header`, `nav`, `main`, `section`, `article`.
- **التصفح بالكيبورد:** دعم كامل للتنقل بالـTab مع وضوح التركيز `:focus-visible`.
- **توافق مع قارئات الشاشة:** التركيز على تجربة مستخدمي NVDA وJAWS.
- **روابط تجاوز (Skip Links):** لتسهيل التنقل للمستخدمين الكفيفين.
- **مراجعة المحتوى قبل النشر:** لن يُنشر أي تطبيق أو رابط إلا بعد مراجعته.
- **مجاني بالكامل:** المشروع غير ربحي وخدمي بحت.
- **احترام المصادر وحقوق النشر:** الإشارة للمصدر الأصلي عند الحاجة.
- **الاستقلالية:** هدف المشروع تمكين المستخدم من التصفح والعثور على ما يحتاجه بمفرده.

## 3. الأقسام الرئيسية المقترحة

- **الرئيسية**
- **التطبيقات والبرامج**
- **قارئات الشاشة**
- **الألعاب الصوتية**
- **قنوات YouTube**
- **قنوات ومجموعات Telegram**
- **الشروحات التعليمية**
- **الأخبار والتحديثات**
- **لوحة الإدارة** (لإضافة المحتوى، مراجعته، ونشره)

## 4. مراحل التنفيذ

| المرحلة | العمل |
|---|---|
| **المرحلة 1** | التخطيط: رسم صفحات الموقع الرئيسية (الرئيسية، قسم التطبيقات، صفحة تفاصيل التطبيق) |
| **المرحلة 2** | تجهيز البنية: إعداد مجلدات المشروع، تثبيت Fastify + EJS + better-sqlite3، وربط CSS العادي |
| **المرحلة 3** | بناء الواجهة الأمامية مع التركيز الكامل على إمكانية الوصول (HTML دلالي، تنقل بالكيبورد، توافق قارئات الشاشة) |
| **المرحلة 4** | بناء قاعدة البيانات ونظام الإدارة لإضافة الموارد، ومراجعتها قبل النشر |
| **المرحلة 5** | اختبار أولي مع قارئ الشاشة (يفضل NVDA) والتأكد من سهولة التنقل والبحث |
| **المرحلة 6** | التوسع تدريجيًا بإضافة باقي الأقسام بعد التأكد من استقرار الأساس |

## 5. ملاحظات هامة

- **نبدأ صغيرًا:** سنبدأ بقسم "التطبيقات والبرامج" فقط، ثم نضيف باقي الأقسام تدريجيًا.
- **CSS عادي:** اخترناه لزيادة التحكم في إمكانية الوصول، والحفاظ على HTML دلالي نقي.
- **EJS مع Fastify:** مناسب جدًا لهذا المشروع، ويقلل الاعتماد على JavaScript في التصفح.
- **SQLite:** مثالي للبداية، بسيط، ولا يحتاج لخادم قاعدة بيانات منفصل.
- **الصيانة مستمرة:** سنحرص على تحديث الروابط والتطبيقات نظرًا لتغيرها السريع.
- **الاختبار الواقعي:** يجب اختبار الموقع مع مستخدمين فعليين من مجتمع المكفوفين قدر الإمكان.
